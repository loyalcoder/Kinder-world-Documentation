# Import Demo
<ul>
    <li>Log into your site as an administrator.</li>
    <li>Please go to WP Dashboard > Kinder-World> Import Demo > Choose your desire demo > click “Import Demo” button(Read all the inscrution carefully).</li>
    <li>If import process get stuck, please refresh the page and click the “Continue & Import” button again.</li>
    <li>Please go to Settings > Permalinks select the radio button “Post name” and scroll down then set “Shop base” then click Save changes button to save the settings.</li>
    <li>We are done!</li>
