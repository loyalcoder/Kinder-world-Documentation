# Main Theme Installation
<p>The theme files need to be uploaded before you can activate the theme for use. There are two ways you can do this, FTP upload or WordPress upload. If you have downloaded All files & Documentation then you need to extract the “kinder-world-main.zip file.</p>
<ul>
    <li>If you are uploading via WordPress upload, please go to WP Dashboard > Appearance > Themes > Add New > Upload Theme > Choose File. Select the zipped file “kinder-world.zip” and then hit “Install Now”. After installing the theme successfully you need to click the “Activate” button to activate the theme.</li>
    <li>If you are uploading via FTP upload, then you need to upload the unzipped folder “kinder-world” to the /wp-content/themes folder of your WordPress installation.</li>
</ul>
