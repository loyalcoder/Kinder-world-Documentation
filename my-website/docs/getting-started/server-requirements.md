# Server Requirements
<ul>
    <li>PHP version 7.4 or greater.</li>
    <li>MySQL version 5.6 or greater OR MariaDB version 10.1 or greater.</li>
    <li>WP Memory: 256 MB or greater</li>
    <li>max_execution_time: 120 (This needs to be increased if your server is slow and cannot import data.)</li>
    <li>PHP Post Max Size: 64 MB or greater</li>
</ul>
