# Footer Bottom
<p>Theme options > Footer > Footer Bottom – From this tab, we can Customize Footer Bottom Section Options. like</p>
<ul>
    <li>Enable/ disable Footer Bottom Section.</li>
    <li>Select Footer Bottom Section style( 3 styles available ).</li>
    <li>Select Footer Bottom Layout( 2 styles available ).</li>
    <li>Set Footer Bottom Background color.</li>
    <li>Set Footer Bottom border color.</li>
    <li>Show/ hide Footer Social Icons.</li>
    <li>Set Footer Social icon color and hover color.</li>
    <li>Set Footer copyright text and Customize color and font property.</li>
</ul>
