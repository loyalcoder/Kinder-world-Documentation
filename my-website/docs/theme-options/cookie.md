# Cookie
<p>Theme options > Cookie – From this tab, we can Customize the Cookie notice bar Options. like</p>
<ul>
    <li>Enable/ disable Cookie Notice.</li>
    <li>Set Notice Bar Background Color.</li>
    <li>Set Notice Text and text color.</li>
    <li>Set Learn More Text, URL, text color and hover color.</li>
    <li>Set Cookie Allow Text, text color and hover color.</li>
    <li>Set Cookie Allow Background Color and Background hover color.</li>
    <li>Set Cookie notice display Position.</li>
    <li>Set Cookie Expire Date.</li>
    <li>Customize Cookie notice font properties.</li>
</ul>
