# Footer Top
<p>Theme options > Footer> Footer Top – From this tab, we can Customize the Footer Top section Options.</p>
<ul>
    <li>Enable/ disable Footer Top Section.</li>
    <li>Customize Footer Top Background property.</li>
    <li>Set Footer Top Background Overlay Color.</li>
    <li>Set Footer Top text color.</li>
    <li>Set Footer Top link color.</li>
    <li>Set Footer Top link hover color.</li>
    <li>Set Footer Top widget title color.</li>
    <li>Customize Footer Top font properties.</li>
    <li>Customize Footer Top widget title font properties.</li>
    <li>Select Footer Layout (boxed, wide).</li>
    <li>Select footer top column.</li>
    <li>Set Footer Padding and margin.</li>
    <li>Select Footer Widgets Alignment.</li>
</ul>
