# Footer
<p>Theme options > Footer – From this tab, We can control some general settings for Footer.</p>
<ul>
    <li>Enable/ disable elementor Footer.</li>
    <li>Select elementor Footer template.</li>
</ul>
<img src="/img/docusaurus.png"/>
<p>N.B: To use an Elementor Footer template, you have to create a Footer template first. Go to WP Dashboard > Templates to create a Footer template.</p>
