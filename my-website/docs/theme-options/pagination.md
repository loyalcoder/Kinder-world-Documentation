# pagination
<p>Theme options > Pagination – From this tab, we can Customize the default theme Pagination Options.</p>
<ul>
    <li>Set Pagination Space.</li>
    <li>Set Pagination Background color and hover color.</li>
    <li>Set Pagination Current Page background color.</li>
    <li>Set Pagination Number Color and hover color.</li>
    <li>Set Pagination Current Page Number color.</li>
    <li>Set Pagination Number and Arrow Size.</li>
    <li>Customize Pagination fonts properties.</li>
</ul>
