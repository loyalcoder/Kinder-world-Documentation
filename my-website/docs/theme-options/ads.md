# Ads
<p>Theme options > Ads – From this tab, we can customize Ads Section options.</p>
<ul>
    <li>Enable/ disable Single Post Ads.</li>
    <li>Set Content ad type (banner/ Adsense).</li>
    <li>Set After paragraph space.</li>
    <li>Upload and select Ad Banner and set URL.</li>
    <li>Or set Adsense codes.</li>
</ul>
