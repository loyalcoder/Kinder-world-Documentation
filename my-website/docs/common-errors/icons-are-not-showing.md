# Social icons and some other icons are not showing correctly
<p>Elementor updated their FontAwesome version 4.xx to 5.xx In this case sometimes you will see some icons like social media icons, carousel arrow icons will not display properly.</p>
<p>For this situation, Elementor released an option to fix it very easily.</p>
<p>To fix it please go to WordPress Dashboard > Elementor > Settings > Advanced > Load Font Awesome 4 Support > change the selected option.</p>
