# Kinder World Documentation

Official documentation for the **Kinder World** WordPress theme and **Kinder World Manager** plugin.

## Local development

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run serve
```

## Documentation sections

- **Getting Started** — requirements and installation
- **Kinder World Manager** — plugin architecture, CPTs, Elementor widgets, Theme Builder
- **Kinder World Theme** — templates, navigation, Tailwind/Webpack build, integration
